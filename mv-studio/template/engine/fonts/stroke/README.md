# Single-stroke fonts (core/stroke.js)

Fonts drawn as pen paths, so a line can be *written* by a moving point. Unmodified SVG fonts:

| name in `Z.stroke` | file | licence |
| --- | --- | --- |
| `sans` | HersheySans1.svg | Hershey (below) |
| `script` | HersheyScript1.svg | Hershey (below) |
| `serif` | HersheySerifMed.svg | Hershey (below) |
| `readable` | EMSReadability.svg | SIL OFL 1.1, `OFL_ems.txt` |
| `allure` | EMSAllure.svg | SIL OFL 1.1, `OFL_ems.txt` |

The SVG conversions are by Windell H. Oskay (Evil Mad Scientist); taken from pdoom-video (MIT, Giacomo Magnanini).

Hershey fonts, acknowledgements required by their licence:
